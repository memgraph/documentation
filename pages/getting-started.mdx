# Getting started with Memgraph

Memgraph is a high-performance, in-memory graph database that powers real-time
AI context. Use it as the graph engine for GraphRAG, AI memory and agentic
applications, and for real-time graph analytics. This page gets Memgraph
running and answering a first query, then points you to the guide for what
you're building.

## Run Memgraph in one command

With [Docker](https://docs.docker.com/engine/install/) running, this command
starts Memgraph with the [MAGE](/advanced-algorithms) graph algorithms and
[Memgraph Lab](/memgraph-lab), the visual interface:

<Tabs items={['Linux/macOS', 'Windows']}>
<Tabs.Tab>
<CodeSnippet code={'curl -sSf "https://install.memgraph.com" | sh'} page="getting-started-top" os="linux/macOS"/>
</Tabs.Tab>
<Tabs.Tab>
<CodeSnippet code="iwr https://install.memgraph.com/windows -useb | iex" page="getting-started-top" os="windows"/>
</Tabs.Tab>
</Tabs>

Then open Memgraph Lab at `http://localhost:3000`. The
[Quickstart](#quickstart) explains what the command starts and walks you
through a first query and a graph algorithm.

## Start with your coding agent

If you work with a coding agent such as Claude Code, Cursor or Codex, paste
this prompt into it. The agent starts Memgraph in Docker, installs the
Memgraph [Agent Skills](/getting-started/coding-with-ai/skills), connects the
[Docs MCP server](/getting-started/coding-with-ai/docs-mcp) and the [Memgraph
MCP server](/ai-ecosystem/integrations/mcp), and runs a first query. You need
Docker running, and Node.js for `npx`.

```plaintext
Set up Memgraph for this project. Add .md to any Memgraph docs URL to read
the page as Markdown. If a container name or port below (7687, 7444, 8000)
is already in use, leave that container alone: start new containers with
unique names on free ports, use those in every step, and tell me which.

1. Start Memgraph with MAGE in Docker, then wait until it accepts queries:
   docker run -d -p 7687:7687 -p 7444:7444 --name memgraph memgraph/memgraph-mage --schema-info-enabled=true
   until echo 'RETURN 1;' | docker exec -i memgraph mgconsole >/dev/null 2>&1; do sleep 1; done
2. Install the Memgraph Agent Skills without prompts, with AGENT set to your
   skills CLI agent name (claude-code, cursor, codex):
   npx skills add memgraph/skills --skill '*' --agent AGENT --yes
3. Connect the Memgraph docs MCP server at https://mcp-docs.memgraph.com.
   In Claude Code: claude mcp add --transport http memgraph-docs https://mcp-docs.memgraph.com
   Other clients: https://memgraph.com/docs/getting-started/coding-with-ai/docs-mcp.md
4. Connect the Memgraph MCP server to this Memgraph. Start it with
   docker run -d --rm -p 8000:8000 --add-host=host.docker.internal:host-gateway memgraph/mcp-memgraph:latest
   (on another Bolt port, add -e MEMGRAPH_URL=bolt://host.docker.internal:PORT)
   and add http://localhost:8000/mcp/ as an HTTP MCP server.
   Details: https://memgraph.com/docs/ai-ecosystem/integrations/mcp.md
5. Run this query and show me the result table:
   echo "CREATE (:Developer {name: 'Ana'})-[:USES]->(:Database {name: 'Memgraph'}); MATCH (d:Developer)-[:USES]->(db:Database) RETURN d.name AS developer, db.name AS database;" | docker exec -i memgraph mgconsole
6. Tell me what you installed, whether I need to start a new session to load
   the skills and MCP servers, and suggest next steps for what I'm building.
```

You should see the agent report the skills and the two MCP servers it added,
and this result table:

```plaintext copy=false
+------------+------------+
| developer  | database   |
+------------+------------+
| "Ana"      | "Memgraph" |
+------------+------------+
```

Some agents load new skills and MCP servers only in a new session. To set up
one of these tools on its own, or to install the skills as a Claude Code
plugin, see [AI coding assistants](/getting-started/coding-with-ai).

## Quickstart

Run Memgraph and [Memgraph Lab](/memgraph-lab), the visual interface, in
Docker, load a sample dataset, and run a query and a graph algorithm on it.
You need [Docker](https://docs.docker.com/engine/install/) installed and
running.

### 1. Start Memgraph and Memgraph Lab [#install-memgraph-platform]

Run the installer for your operating system:

<Tabs items={['Linux/macOS', 'Windows']}>
<Tabs.Tab>
<CodeSnippet code={'curl -sSf "https://install.memgraph.com" | sh'} page="getting-started" os="linux/macOS"/>
</Tabs.Tab>
<Tabs.Tab>
<CodeSnippet code="iwr https://install.memgraph.com/windows -useb | iex" page="getting-started" os="windows"/>
</Tabs.Tab>
</Tabs>

The script downloads a [Docker Compose
file](https://github.com/memgraph/memgraph-platform/blob/main/docker-compose.yml)
into a `memgraph-platform` folder in your home directory and starts two
containers:

- `memgraph-mage`: Memgraph with [MAGE](/advanced-algorithms), the graph
  algorithms library, on port `7687` for queries and `7444` for logs.
- `memgraph-lab`: Memgraph Lab on port `3000`.

To stop both containers, run `docker compose stop` in the `memgraph-platform`
folder, and `docker compose start` to start them again. For other
ways to run Memgraph, see [Installation](/getting-started/install-memgraph).

### 2. Open Memgraph Lab

Open `http://localhost:3000` in your browser. Lab opens on the **Quick
connect** screen; click **Connect now** to connect to Memgraph:

![Memgraph Lab Quick connect screen with the Connect now button](/pages/getting-started/lab.png)

To query from the terminal instead, run `docker exec -it memgraph-mage
mgconsole`. For other ways to run mgconsole, see [CLI](/getting-started/cli).

### 3. Load a dataset

In the Lab sidebar, open **Datasets**, find **Capital cities and borders** and
click **Load dataset**:

![Datasets section in Memgraph Lab, with the Load dataset button on the Capital cities and borders dataset](/pages/getting-started/first-steps/memgraph-lab-datasets.png)

### 4. Run a query

Open **Query execution**, paste this query into the **Cypher editor** and
click **Run query**. It returns every pair of connected nodes and the
relationship between them, 738 rows on this dataset:

```cypher
MATCH (n)-[r]-(m)
RETURN n, r, m;
```

The **Graph results** tab draws the capital cities on a world map, connected
by their borders:

![Capital cities and borders dataset in the Graph results tab of Memgraph Lab, drawn as cities on a world map](/pages/getting-started/first-steps/memgraph-lab-first-cypher-query.png)

### 5. Run a graph algorithm

Run [PageRank](/advanced-algorithms/available-algorithms/pagerank) with the
`pagerank.get()` procedure from MAGE and return the five highest-ranked
cities:

```cypher
CALL pagerank.get()
YIELD node, rank
RETURN node.name AS city, rank
ORDER BY rank DESC
LIMIT 5;
```

The **Data results** tab shows these rows:

```plaintext copy=false
+--------------+--------------+
| city         | rank         |
+--------------+--------------+
| "Porto-Novo" | 0.0200067    |
| "Gitega"     | 0.0184617    |
| "Thimphu"    | 0.0140559    |
| "Nur-Sultan" | 0.0140246    |
| "Dodoma"     | 0.0139278    |
+--------------+--------------+
```

For the other algorithms you can run the same way, see
[available algorithms](/advanced-algorithms/available-algorithms).
