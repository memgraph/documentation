# Install Memgraph on Kubernetes

Run Memgraph on Kubernetes with the charts in the Memgraph Helm chart
repository. There are charts for a single instance, a high availability cluster
and tools that connect to Memgraph:

| Chart | What it deploys |
|---|---|
| [Standalone Helm chart](/deployment/environments/kubernetes/standalone-helm-chart) | One Memgraph instance |
| [Kubernetes operator](/deployment/environments/kubernetes/operator) or [HA Helm chart](/deployment/environments/kubernetes/ha-helm-chart) | A Memgraph [high availability](/database-management/clustering/high-availability) cluster, which needs a [Memgraph Enterprise license](/database-management/enabling-memgraph-enterprise) |
| [Memgraph Lab Helm chart](/deployment/environments/kubernetes/lab-helm-chart) | [Memgraph Lab](/memgraph-lab), a visual interface for querying Memgraph |
| [MCP server Helm chart](/deployment/environments/kubernetes/mcp-helm-chart) | The Memgraph [MCP server](/ai-ecosystem/integrations/mcp), which connects AI agents to Memgraph |

To choose between them and configure them, see
[Kubernetes](/deployment/environments/kubernetes).

The steps below install a single instance with the standalone Helm chart,
connect to it and uninstall it.

## Prerequisites

- A Kubernetes cluster, with `kubectl` configured for it. On minikube, set up
  storage first, as in [Install with
  minikube](/deployment/environments/kubernetes/standalone-helm-chart#install-with-minikube).
- [Helm](https://helm.sh/docs/intro/install/) 3.

## 1. Install the chart

Add the Memgraph Helm chart repository and install the chart as a release named
`memgraph`:

```bash
helm repo add memgraph https://memgraph.github.io/helm-charts
helm repo update
helm install memgraph memgraph/memgraph
```

The chart creates a `StatefulSet` with one pod, `memgraph-0`, and a service
named `memgraph` on the Bolt port, 7687.

## 2. Connect to Memgraph

Wait for the pod to become ready:

```bash
kubectl wait --for=condition=Ready pod/memgraph-0 --timeout=300s
```

Run [`mgconsole`](/getting-started/cli) inside the pod:

```bash
kubectl exec -it memgraph-0 -- mgconsole
```

To connect from your machine with [Memgraph Lab](/memgraph-lab) or a [client
library](/client-libraries), forward the Bolt port and connect to
`localhost:7687`:

```bash
kubectl port-forward svc/memgraph 7687:7687
```

## 3. Uninstall Memgraph

Remove the release:

```bash
helm uninstall memgraph
```

Helm keeps the `PersistentVolumeClaims` that hold the data and logs, so a new
release with the same name starts with the same data. To delete the data, list
the claims with `kubectl get pvc` and delete them with `kubectl delete pvc`.

## Next steps
