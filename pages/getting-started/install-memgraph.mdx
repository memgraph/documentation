# Install Memgraph

Memgraph runs in Docker, on Kubernetes, in Memgraph Cloud and as a native Linux
package. To try it on your machine first, follow the
[quickstart](/getting-started#quickstart), which starts Memgraph with
[MAGE](/advanced-algorithms) and [Memgraph Lab](/memgraph-lab) in Docker.

## Installation options

Pick the option that matches where Memgraph will run:

- [Docker](/getting-started/install-memgraph/docker) or [Docker
  Compose](/getting-started/install-memgraph/docker-compose): development, and
  production on a single machine. Use the `memgraph/memgraph-mage` image unless
  you need the slim `memgraph/memgraph` image without graph algorithms.
- [Memgraph Cloud](/getting-started/install-memgraph/memgraph-cloud): a managed
  instance.
- [Kubernetes](/getting-started/install-memgraph/kubernetes): standalone or
  high-availability deployments with Helm charts.
- Linux packages: a native install on
  [Debian](/getting-started/install-memgraph/debian),
  [Ubuntu](/getting-started/install-memgraph/ubuntu),
  [CentOS](/getting-started/install-memgraph/centos),
  [Fedora](/getting-started/install-memgraph/fedora),
  [Rocky](/getting-started/install-memgraph/rocky) or [Red
  Hat](/getting-started/install-memgraph/redhat), or on Windows through
  [WSL](/getting-started/install-memgraph/wsl). The package files are also on
  [Direct download links](/getting-started/install-memgraph/direct-download-links).
- [Source build](/getting-started/install-memgraph/build-from-source) and
  [Packaging](/getting-started/install-memgraph/packaging): compile Memgraph
  yourself or build your own `.deb` or `.rpm` package.

<Callout type="info">
Since Memgraph 3.13, there is one `.deb` package for all Debian-family
distributions and one `.rpm` package for all RHEL-family distributions, per
architecture. The distribution pages install the same package and differ only
in their setup steps.
</Callout>

Before you run Memgraph, check the [system configuration
guidelines](/database-management/system-configuration), especially the
`vm.max_map_count` parameter.

## System requirements

Native Linux packages run on any Linux with glibc 2.31 or newer: Debian 12+,
Ubuntu 22.04+, RHEL, CentOS and Rocky 9+, and Fedora 42+.

Memgraph requires **Python 3.10 or newer** on the host, for Python query modules
and the auth and SSO modules. Memgraph uses the host's Python at runtime, so any
version from 3.10 up works. On distributions whose default `python3` is older
(such as CentOS 9 with 3.9), the package installs and uses a newer interpreter.
Docker images already include a suitable Python.

The minimum and recommended hardware:

|                    | Minimum                                                                                                                   | Recommended                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| CPU                | Server or desktop processor: <br/> Intel Xeon <br/> AMD Opteron/Epyc <br/> ARM machines or Apple M1 <br/> Amazon Graviton | Server processor: <br/> Intel Xeon <br/> AMD Opteron/Epyc <br/> ARM machines or Apple M1 <br/> Amazon Graviton |
| RAM                | 1 GB                                                                                                                      | ≥ 16 GB ECC                                                                                                    |
| Disk               | 1 GB                                                                                                                      | at least 3x the amount of RAM (NVMe SSD, mirroring RAID 1)                                                     |
| Cores              | 1 vCPU                                                                                                                    | ≥ 8 vCPUs (≥ 4 physical cores)                                                                                 |
| Network Throughput | 100 Mbps                                                                                                                  | ≥ 1 Gbps                                                                                                       |
| Network Latency    | < 10ms                                                                                                                    | < 1ms                                                                                                          |


The disk is used for storing database [durability files](/fundamentals/data-durability), including snapshots and write-ahead
logs. By default, Memgraph keeps the **three most recent snapshots**; set the
`--storage-snapshot-retention-count` flag to change that. A snapshot is
usually smaller than the RAM needed to load the same data into memory.

The number of CPU cores you need depends on your workload. More cores let
Memgraph run more queries in parallel.

To size RAM for your data, see [storage memory
usage](/fundamentals/storage-memory-usage).
