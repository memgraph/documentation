# llms.txt and Markdown pages

AI coding agents can read the Memgraph docs directly, without rendering the
website and without installing anything. Every docs page has a plain Markdown
version, and `llms.txt` files list those pages so an agent can find the one it
needs.

## Docs indexes and Markdown pages

- **`llms.txt`:** [`https://memgraph.com/docs/llms.txt`](/llms.txt) lists the
  main pages of each docs section with a one-line description, in the same
  order as the sidebar. Reference material that an agent can skip when its
  context is short, such as release notes, is grouped under **Optional**.
- **Section `llms.txt` files:** each section has its own `llms.txt` with all
  of its pages, for example `https://memgraph.com/docs/querying/llms.txt`. The
  root `llms.txt` links to them.
- **Markdown pages:** add `.md` to any docs URL to get the page as Markdown,
  for example `https://memgraph.com/docs/querying.md`. Every link in the
  `llms.txt` files points at the Markdown version.

The rest of the Memgraph website has its own index at
[`https://memgraph.com/llms.txt`](https://memgraph.com/llms.txt).

## Point your agent at the docs

Add the `llms.txt` URL to your agent's project instructions, for example
`CLAUDE.md`, `AGENTS.md` or Cursor rules:

```plaintext
Memgraph documentation: https://memgraph.com/docs/llms.txt
```

When a task needs Memgraph, the agent can open the index and the Markdown pages
it lists. To let the agent search the docs instead of reading the index,
connect the [Docs MCP server](/getting-started/coding-with-ai/docs-mcp).
