# Use an AI coding assistant

AI coding agents such as Claude Code, Cursor and Codex don't know Memgraph well
by default. Give them Memgraph-specific knowledge and direct access to the
current docs so they write correct Cypher and follow Memgraph's recommended
practices.

- [Agent Skills](/getting-started/coding-with-ai/skills): Install skills that teach
  your agent how to write Cypher, model graph data, run MAGE algorithms and
  build query modules for Memgraph.
- [Docs MCP server](/getting-started/coding-with-ai/docs-mcp): Let your assistant
  search the Memgraph documentation and answer with sources.

To let an agent query your own database, use the [Memgraph MCP
server](/ai-ecosystem/agentic-applications/mcp).

## Machine-readable docs

Agents can also read the docs directly, without rendering the website.

- **llms.txt:** [`https://memgraph.com/docs/llms.txt`](https://memgraph.com/docs/llms.txt)
  lists every docs page with a one-line description, in the same order as the
  sidebar. Reference material that an agent can skip when its context is
  tight, such as release notes, is grouped under **Optional**. The rest of the
  Memgraph website has its own index at
  [`https://memgraph.com/llms.txt`](https://memgraph.com/llms.txt).
- **Markdown pages:** add `.md` to any docs URL to get the page as plain
  Markdown, for example `https://memgraph.com/docs/querying.md`. Every link in
  `llms.txt` already points at the Markdown version.

To point your agent at the docs, add the `llms.txt` URL to its project
instructions, for example `CLAUDE.md`, `AGENTS.md` or Cursor rules:

```
Memgraph documentation: https://memgraph.com/docs/llms.txt
```
