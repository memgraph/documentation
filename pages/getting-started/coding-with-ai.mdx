# AI coding assistants

AI coding agents such as Claude Code, Cursor and Codex don't know Memgraph well
by default. Give them Memgraph-specific knowledge and access to the current
docs, so they write correct Cypher and follow Memgraph's recommended practices.

To set up Memgraph, the Agent Skills and both MCP servers in one step, paste
the prompt from [Start with your coding
agent](/getting-started#start-with-your-coding-agent) into your agent.

## Choose what to give your agent

You can combine these, depending on what the agent needs:

| Your agent needs to | Use |
| --- | --- |
| Write Cypher, model data and use MAGE correctly, with knowledge it loads when a task needs it | [Agent Skills](/getting-started/coding-with-ai/skills) |
| Look up the current docs and answer with sources | [Docs MCP server](/getting-started/coding-with-ai/docs-mcp) |
| Read the docs without installing anything | [`llms.txt` and Markdown pages](/getting-started/coding-with-ai/llms-txt) |
| Query your own Memgraph database | [Memgraph MCP server](/ai-ecosystem/integrations/mcp) |
| Remember what it did in earlier sessions | [AI memory](/ai-ecosystem/ai-memory), which records your agent's sessions in Memgraph |

## Machine-readable docs

Agents can also read the docs without installing anything: every page has a
Markdown version, and `llms.txt` files list them by section. See [llms.txt and
Markdown pages](/getting-started/coding-with-ai/llms-txt) for the URLs and how
to add them to your agent's instructions.
