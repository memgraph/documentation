# Deprecated features

This section lists the configuration flags which have been deprecated, removed
or replaced in Memgraph, and the versions where the changes happened.

Removing a flag is a three-part process:
- From the **Deprecated in** version, the flag still works, but it is announced as going away.
- From the **Ignored from** version, Memgraph accepts the flag, but the flag has no effect.
- From the **Rejected from** version, Memgraph does not recognise the flag and fails to start if the flag is specified.

## Currently deprecated

| Feature | Deprecated in | Ignored from | Rejected from | Replacement |
| ------- | ------------- | ------------ | ------------- | ----------- |
| `JSON` value of `--metrics-format` | 3.11 | Not yet | Not yet | [`--metrics-format=OpenMetrics`](/database-management/monitoring#openmetrics-monitoring). `JSON` still works, but the default changed to `OpenMetrics` in 3.13, so pass `--metrics-format=JSON` to keep it. See [Migrating from JSON to OpenMetrics](/database-management/monitoring#migrating-from-json-to-openmetrics). |
