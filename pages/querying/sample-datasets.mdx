# Sample datasets

Memgraph publishes sample graph datasets that you can load to try Cypher
queries, [graph algorithms](/advanced-algorithms) and [Memgraph
Lab](/memgraph-lab) visualizations. Each dataset is a [CYPHERL
file](/data-migration/cypherl): Cypher queries that create its indexes, nodes
and relationships.

## Load a dataset

Load a dataset into an empty database. Loading it again, or into a database
that already has data, adds a second copy of its nodes and relationships. To
empty the database first, run:

```cypher
MATCH (n) DETACH DELETE n;
```

You can load a dataset with mgconsole or with Memgraph Lab.

### With mgconsole

If Memgraph runs in Docker, download the dataset's file and pipe it into
[mgconsole](/getting-started/cli) inside the container. This command loads
Capital cities and borders:

```bash
curl -fsSL https://download.memgraph.com/datasets/country-capitals/cypherl/dataset.cypherl.gz | gunzip | docker exec -i CONTAINER_NAME mgconsole
```

`CONTAINER_NAME` is the name of your Memgraph container: `memgraph-mage` if
you started Memgraph with the [Getting started
installer](/getting-started#install-memgraph-platform). For another dataset,
use its file link from the [list of datasets](#available-datasets).

Check that the counts match the dataset's row in the list. For Capital cities
and borders:

```cypher
MATCH (n) RETURN count(n) AS nodes;
```

```plaintext copy=false
+-------+
| nodes |
+-------+
| 212   |
+-------+
```

### With Memgraph Lab

In Memgraph Lab, open **Datasets** in the sidebar, find the dataset and click
**Load dataset**. Lab lists the datasets from the same catalog as the list
below.

## Available datasets

The datasets are listed by title. The slug is the dataset's name in its file
link, and the file link is what the [mgconsole command](#with-mgconsole)
loads. The same list is available as JSON at
`https://download.memgraph.com/datasets/items.v1.json`, with each dataset's
graph model and sample queries.
