# Telemetry

MemGQL sends a small amount of anonymous usage data to Memgraph. It never
includes your data, schema, or queries.

`SHOW CONFIG;` reports the setting as `telemetry.enabled`.

## What is sent

- **At start and shutdown:** timestamp, MemGQL version, license mode
  (community or enterprise), connector mode, and basic host facts: hostname,
  operating system, CPU architecture, core count, total memory, and whether it
  runs in a container.
- **Every 8 hours:** the peak number of connectors, connections, and graphs
  since start, and the number of node and edge mappings registered.
- **With every record:** a random install id and run id so servers can be told
  apart.

## Disable it

If required, it's possible to disable sending statistical data by starting the
server with the flag:
```bash
docker run --rm -p 7688:7688 memgraph/memgql:latest --telemetry-enabled=false
```

If Memgraph's telemetry server is unreachable, records are kept in a local
`memgql_telemetry.redb` file next to the server and sent later.
