# Memgraph's AI ecosystem

AI drives a wide range of innovations, from machine learning (ML) models to
natural language processing (NLP) systems and beyond. These technologies
frequently intersect, enabling the creation of powerful applications with
Generative AI (GenAI), including advanced chatbots and agents.

Memgraph offers a robust ecosystem designed to support AI applications, featuring
built-in processing capabilities and integrations with popular Agentic Frameworks. This
ecosystem empowers developers to build sophisticated GenAI solutions that leverage
the strengths of graph databases. 

![Memgraph AI Ecosystem](/pages/ai-ecosystem/memgraph-ai-ecosystem.png)

## What you'll find here

This section of Memgraph’s documentation is your guide to using Memgraph for AI:

- [GraphRAG](/ai-ecosystem/graph-rag): See how knowledge graphs enable more
  accurate and scalable RAG systems. Create a knowledge graph from structured or
  unstructured data, retrieve context with Memgraph's retrieval pipelines, and
  let an agent pick the right pipeline for each question.
- [Framework integrations](/ai-ecosystem/integrations): Use Memgraph with
  popular AI frameworks, including **LangChain**, **LlamaIndex**, **LightRAG**,
  **Cognee** and **Mem0**.
- [Memgraph MCP server](/ai-ecosystem/mcp): Connect LLM clients such as Claude
  to your Memgraph database over the Model Context Protocol (MCP).
- [Coding with AI](/ai-ecosystem/coding-with-ai): Help AI coding agents work
  with Memgraph using Agent Skills, the Docs MCP server and machine-readable
  docs.
- [Use cases](/ai-ecosystem/use-cases): Follow end-to-end walkthroughs with
  runnable scripts for agentic GraphRAG, AI memory and agentic AI.
- [Machine learning](/ai-ecosystem/machine-learning): Learn how Memgraph powers
  ML workflows with node embeddings and graph neural networks.
- [GraphChat in Memgraph Lab](/memgraph-lab/features/graphchat): Ask questions
  about your graph in natural language.
