# Memgraph's AI ecosystem

Memgraph works with AI in four ways. Pick the one that matches what you are
doing.

![Memgraph AI Ecosystem](/pages/ai-ecosystem/memgraph-ai-ecosystem.png)

## Build AI apps

Use Memgraph as the context and memory layer of a GenAI application.

- [GraphRAG](/ai-ecosystem/graph-rag): Build retrieval on a knowledge graph,
  from data modeling to atomic pipelines and agentic GraphRAG.
- [Integrations](/ai-ecosystem/integrations): Use Memgraph from LangChain,
  LlamaIndex, Cognee, Mem0 and LightRAG.
- [Machine learning](/ai-ecosystem/machine-learning): Node embeddings, graph
  neural networks and temporal graph networks.
- [GraphChat in Memgraph Lab](/memgraph-lab/features/graphchat): Ask questions
  about your graph in natural language.

## Load data with AI

Let an LLM-powered agent build the graph for you.

- [SQL2Graph](/ai-ecosystem/agents/sql2graph-agent): Migrate a relational
  database to a graph.
- [Unstructured2Graph](/ai-ecosystem/agents/unstructured2graph-agent): Turn
  documents into a knowledge graph.

## Code with AI agents

Give your coding agent, such as Claude Code, Cursor or Codex, what it needs to
work with Memgraph.

- [Agent Skills](/ai-ecosystem/skills): Memgraph knowledge your agent loads
  when it writes Cypher, models data or runs algorithms.
- [Memgraph MCP server](/ai-ecosystem/mcp): Let an agent query and explore your
  Memgraph database.

## Docs for AI

Get these docs into your AI assistant.

- [Docs MCP server](/ai-ecosystem/docs-mcp): Let your assistant search the
  current docs and answer with sources.
- [llms.txt and Markdown pages](/ai-ecosystem/llms-txt): Read the docs as
  plain Markdown, starting from one index.
