# llms.txt and Markdown pages

Memgraph docs publish an [llms.txt](https://llmstxt.org/) index and a plain
Markdown version of every page, so AI agents and assistants can read the docs
without rendering the website.

## llms.txt

[`https://memgraph.com/docs/llms.txt`](https://memgraph.com/docs/llms.txt)
lists every docs page with a one-line description, in the same order as the
sidebar. Reference material that an agent can skip when its context is tight,
such as release notes and the full list of algorithms, is grouped under
**Optional**.

The rest of the Memgraph website has its own index at
[`https://memgraph.com/llms.txt`](https://memgraph.com/llms.txt).

## Markdown version of any page

Add `.md` to any docs URL to get the page as plain Markdown:

```
https://memgraph.com/docs/querying     → web page
https://memgraph.com/docs/querying.md  → Markdown
```

Every link in `llms.txt` already points at the Markdown version.

## Point your agent at the docs

Add the `llms.txt` URL to your agent's project instructions, for example
`CLAUDE.md`, `AGENTS.md` or Cursor rules:

```
Memgraph documentation: https://memgraph.com/docs/llms.txt
```

To let your assistant search the docs instead of fetching pages one by one,
connect the [Docs MCP server](/ai-ecosystem/docs-mcp).
