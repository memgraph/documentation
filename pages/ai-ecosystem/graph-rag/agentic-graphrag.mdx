# Agentic GraphRAG

In Agentic GraphRAG, an agent reads the question, chooses the retrieval
pipeline that fits it and runs it on the knowledge graph. Because each
[Atomic GraphRAG](/ai-ecosystem/graph-rag/atomic-pipelines) pipeline is one
Cypher query, the agent only has to write or pick one query per question.

The three pipelines match three types of question:

| Pipeline | Question type | Example |
| --- | --- | --- |
| [Text2Cypher](/ai-ecosystem/graph-rag/atomic-pipelines/text2cypher) | Analytical | "How many organizations of each type are covered?" |
| [Local graph search](/ai-ecosystem/graph-rag/atomic-pipelines/local-graph-search) | Local | "What is connected to NVIDIA?" |
| [Query-focused summarization](/ai-ecosystem/graph-rag/atomic-pipelines/query-focused-summarization) | Global | "What are the main themes overall?" |

An agent can also combine the building blocks of the pipelines in its own way
when a question doesn't fit one type.

## Let an agent choose the pipeline

The agent needs two things:

- **A connection to Memgraph.** Most agents run queries through the [Memgraph
  MCP server](/ai-ecosystem/integrations/mcp). [Memgraph Lab](/memgraph-lab)
  has an agent built in, [GraphChat](/memgraph-lab/features/graphchat), that
  is already connected.
- **Instructions for choosing a pipeline.** The [GraphRAG
  skill](https://github.com/memgraph/skills/tree/main/skills/memgraph-graph-rag)
  tells the agent which pipeline to use for which question. For the other
  Memgraph skills, see [Agent Skills](/getting-started/coding-with-ai/skills).

For example, in GraphChat:

```plaintext
Using https://github.com/memgraph/skills/blob/main/skills/memgraph-graph-rag/SKILL.md,
what's the most important person in the dataset?
```

The agent classifies the question, then runs the steps of the pipeline it
chose, or a combination of steps from several pipelines:

![The agent classifies a user question and runs schema info and Cypher, pivot search, relevance expansion and ranking, or another combination of steps, to build the context for the answer](/pages/ai-ecosystem/graph-rag/agentic-graphrag/agentic-graphrag.png)

## Run the example

The example loads a knowledge graph of finance news, runs all three pipelines
on it as Cypher queries and starts the Memgraph MCP server, so your own agent
can query the same graph. If you set an OpenAI API key, it also starts an
agent app that chooses the pipeline for each question.

You need:

- [Docker](https://docs.docker.com/get-docker/)
- [git](https://git-scm.com/downloads)
- For the agent app only: [Python](https://www.python.org/downloads/) 3.10–3.13
  and an OpenAI API key. The app's dependencies don't support Python 3.14 yet;
  the script picks a compatible Python if you have one.

The scripts are `agentic-graphrag.sh` and `agentic-graphrag.ps1` in the
[memgraph/memgraph-platform](https://github.com/memgraph/memgraph-platform/tree/main/code-examples)
repository. To remove what the example created, download the script and run it
with `clean`; when you run it from the web, it prints the `docker` commands
that do the same. If Windows blocks the script, allow scripts for the current
session first: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`.

The steps below show what the script does.

## 1. Start Memgraph and the MCP server

Memgraph starts with schema info enabled, so a connected agent can read the
graph's schema. The MCP server connects to it over the Docker network:

```bash
docker network create agenticgraphrag-net

docker run -d --name agenticgraphrag-memgraph --network agenticgraphrag-net \
  -p 7687:7687 \
  memgraph/memgraph-mage:3.12.0 --schema-info-enabled=True

docker run -d --name agenticgraphrag-mcp --network agenticgraphrag-net \
  -p 8000:8000 --env MEMGRAPH_URL=bolt://agenticgraphrag-memgraph:7687 \
  memgraph/mcp-memgraph:0.2.0
```

## 2. Load the knowledge graph

The dataset is a `.cypherl` file of queries. `mgconsole` reads a limited
amount of input per call, so the script sends the file in batches of 300 lines
over the Docker network, which works the same on Linux, macOS and Windows:

```bash
lines=$(wc -l < asknews-finance-graph.cypherl); batch=300; start=1
while [ "$start" -le "$lines" ]; do
  sed -n "${start},$((start + batch - 1))p" asknews-finance-graph.cypherl \
    | docker run -i --rm --network agenticgraphrag-net memgraph/mgconsole:1.6.0 \
        --host agenticgraphrag-memgraph --port 7687
  start=$((start + batch))
done
```

The graph has about 1,000 nodes and 1,600 relationships: organizations,
people, markets and events from finance news. To use your own data, load your
own `.cypherl` file instead.

## 3. Run the three pipelines

Each pipeline is one Cypher query. The agent in the next step only decides
which one to run.

**Text2Cypher** answers an analytical question with one aggregating query:

```cypher
MATCH (n:organization) WHERE n.detailed_type IS NOT NULL
RETURN n.detailed_type AS organization_type, count(*) AS count
ORDER BY count DESC LIMIT 8;
```

**Local graph search** starts from one entity and expands to its neighborhood
in one traversal. In production, a vector search finds the starting entity;
this example finds it by name:

```cypher
MATCH (seed {id: 'nvidia'})-[*1..2]-(context)
RETURN DISTINCT context.id AS related_entity, context.main_type AS type
LIMIT 10;
```

**Query-focused summarization** ranks the whole graph with
[PageRank](/advanced-algorithms/available-algorithms/pagerank) to find the
central themes, which an LLM then summarizes:

```cypher
CALL pagerank.get() YIELD node, rank
RETURN node.id AS theme, node.main_type AS type, round(rank * 10000) / 10000 AS importance
ORDER BY importance DESC LIMIT 10;
```

On this graph, the top themes are "federal reserve", "us stock market" and
"wall street".

## 4. Let an agent choose the pipeline

This step is optional. There are two ways to add an agent:

- **The agent app.** If `OPENAI_API_KEY` is set, the script creates a Python
  virtual environment, installs the app's dependencies (Streamlit, the Neo4j
  Python driver, `sentence-transformers` and `openai`) and starts the app:

  ```bash
  streamlit run agenticGraphRAG.py
  ```

  The agent classifies each question and runs the matching pipeline. It
  decides on its own, so the same question can take different paths in
  different runs. The app connects to Memgraph on port 7687.

- **Your own agent.** The MCP server is already running, so any agent that
  supports MCP, such as Claude Desktop, Cursor or VS Code, can query the same
  graph. Add the server to the agent's MCP configuration:

  ```json
  {
    "mcpServers": {
      "memgraph": {
        "url": "http://localhost:8000/mcp/"
      }
    }
  }
  ```

  The agent then has tools such as `run_query`, `get_schema`, `get_page_rank`
  and `search_node_vectors`, the same building blocks the three pipelines use.
