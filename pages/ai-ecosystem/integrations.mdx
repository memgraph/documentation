# Tools and integrations

Connect your AI application to Memgraph with the Memgraph MCP server, or use
Memgraph from the AI framework you already work with.

- [Memgraph MCP server](/ai-ecosystem/integrations/mcp): Connect agents and LLM
  clients such as Claude to your Memgraph database over the Model Context
  Protocol (MCP).
- [LangChain](/ai-ecosystem/integrations/langchain): Build agentic applications
  with the Memgraph toolkit, and create and query knowledge graphs.
- [LlamaIndex](/ai-ecosystem/integrations/llamaindex): Create a knowledge graph
  from unstructured data and query it in natural language.
- [LightRAG](/ai-ecosystem/integrations/lightrag): Use Memgraph as the graph
  storage for LightRAG's retrieval-augmented generation.
- [Cognee](/ai-ecosystem/integrations/cognee): Extract concepts and
  relationships from text and search them as a knowledge graph.
- [Mem0](/ai-ecosystem/integrations/mem0): Store and query AI agent memory as a
  graph, with Mem0 1.x.

The diagram groups frameworks that work with Memgraph by what they do:
knowledge graph creation, agent memory and agent frameworks.

## Memgraph Toolbox

The [Memgraph Toolbox](https://github.com/memgraph/ai-toolkit/tree/main/memgraph-toolbox)
is a Python library of tools for querying and inspecting a Memgraph database,
such as running Cypher and searching the graph schema. The Memgraph MCP server and the LangChain integration are built on it, and you can
call the same tools from your own code or framework.

```bash
pip install memgraph-toolbox
```

The toolbox is part of the [Memgraph AI
Toolkit](https://github.com/memgraph/ai-toolkit), which also includes the MCP
server, the LangChain and LightRAG integrations, Unstructured2Graph, SQL2Graph
and Context Graph.
