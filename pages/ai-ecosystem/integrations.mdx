# AI Toolkit and integrations

The [Memgraph AI Toolkit](https://github.com/memgraph/ai-toolkit) is a set of
open-source Python packages for building AI applications on Memgraph:
knowledge graph creation, AI memory, GraphRAG and framework integrations. Each
package installs on its own. Memgraph also works with
[AI frameworks maintained by other projects](#third-party-integrations).

The diagram shows how the toolkit packages build on each other and on
Memgraph. Most are built on memgraph-toolbox; hygm defines a graph schema and
doesn't connect to Memgraph itself. The third-party integrations connect to
Memgraph directly.

## AI Toolkit packages

Each package has its own page in these docs, except hygm and
memgraph-toolbox, which are documented in their READMEs.

| Package | What it does | Docs |
|---|---|---|
| [Context Graph](https://github.com/memgraph/ai-toolkit/tree/main/context-graph) | Gives coding agents memory across sessions and tools, stored in Memgraph. | [AI memory](/ai-ecosystem/ai-memory) |
| [unstructured2graph](https://github.com/memgraph/ai-toolkit/tree/main/unstructured2graph) | Extracts entities and relationships from documents into a knowledge graph. | [Unstructured2Graph](/ai-ecosystem/knowledge-graph-creation/unstructured2graph-agent) |
| [SQL2Graph](https://github.com/memgraph/ai-toolkit/tree/main/agents/sql2graph) | Migrates a MySQL or PostgreSQL database into a graph. | [SQL2Graph](/ai-ecosystem/knowledge-graph-creation/sql2graph-agent) |
| [hygm](https://github.com/memgraph/ai-toolkit/tree/main/hygm) | Defines and validates a graph's node and relationship types (its ontology). | [README](https://github.com/memgraph/ai-toolkit/tree/main/hygm) |
| [mcp-memgraph](https://github.com/memgraph/ai-toolkit/tree/main/integrations/mcp-memgraph) | Connects MCP clients and agents to a Memgraph database. | [Memgraph MCP server](/ai-ecosystem/integrations/mcp) |
| [langchain-memgraph](https://github.com/memgraph/ai-toolkit/tree/main/integrations/langchain-memgraph) | Queries Memgraph in natural language and builds LangChain agents. | [LangChain](/ai-ecosystem/integrations/langchain) |
| [lightrag-memgraph](https://github.com/memgraph/ai-toolkit/tree/main/integrations/lightrag-memgraph) | Uses Memgraph as LightRAG's graph storage. | [LightRAG](/ai-ecosystem/integrations/lightrag) |
| [memgraph-toolbox](https://github.com/memgraph/ai-toolkit/tree/main/memgraph-toolbox) | Runs Cypher and inspects a Memgraph database from Python. | [README](https://github.com/memgraph/ai-toolkit/tree/main/memgraph-toolbox) |

To report a bug or request a feature in any of these packages, open an issue
on [GitHub](https://github.com/memgraph/ai-toolkit/issues).

## Third-party integrations

These frameworks maintain their own Memgraph integration:

- [LlamaIndex](/ai-ecosystem/integrations/llamaindex): Create a knowledge graph
  from unstructured data and query it in natural language.
- [Cognee](/ai-ecosystem/integrations/cognee): Extract concepts and
  relationships from text and search them as a knowledge graph.
- [Mem0](/ai-ecosystem/integrations/mem0): Store and query AI agent memory as a
  graph, with Mem0 1.x.
