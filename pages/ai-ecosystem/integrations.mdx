# Integrations

Memgraph offers several integrations with popular AI frameworks to help you
customize and build your own GenAI application from scratch. Here is a list of
Memgraph's officially supported integrations:

- [LangChain](/ai-ecosystem/integrations/langchain): Build agentic applications
  with the Memgraph toolkit, and create and query knowledge graphs.
- [LlamaIndex](/ai-ecosystem/integrations/llamaindex): Create a knowledge graph
  from unstructured data and query it in natural language.
- [LightRAG](/ai-ecosystem/integrations/lightrag): Use Memgraph as the graph
  storage for fast retrieval-augmented generation.
- [Cognee](/ai-ecosystem/integrations/cognee): Extract concepts and
  relationships from text and search them as a knowledge graph.
- [Mem0](/ai-ecosystem/integrations/mem0): Store and query AI agent memory as a
  graph.

To connect an LLM client such as Claude directly to your database, use the
[Memgraph MCP server](/ai-ecosystem/mcp).
