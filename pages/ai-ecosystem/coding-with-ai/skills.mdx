Memgraph Agent Skills give AI coding agents, such as Claude Code, Cursor and
Codex, Memgraph-specific knowledge they don't have by default. Once installed,
an agent loads the matching skill automatically when a task needs it, for
example when writing Cypher, designing a graph model or running a MAGE
algorithm.

The skills follow the open [Agent Skills
specification](https://agentskills.io/specification), so they work with any
agent that supports it.

## Install

### Claude Code

Add the Memgraph marketplace and install the plugin:

```
/plugin marketplace add memgraph/skills
/plugin install memgraph@memgraph
```

### Any agent

Install all skills with the [`skills` CLI](https://skills.sh):

```bash
npx skills add memgraph/skills
```

To install a single skill, pass its name:

```bash
npx skills add memgraph/skills --skill memgraph-cypher-syntax
```

### Manual install

Clone the repository and symlink the `skills` directory into the location your
agent scans, for example `.claude/skills` for Claude Code or `.cursor/skills`
for Cursor:

```bash
git clone https://github.com/memgraph/skills.git ~/.memgraph-skills
cd /path/to/your/project
ln -s ~/.memgraph-skills/skills .claude/skills
```

## Available skills

| Skill | Use it when you need to |
|-------|-------------------------|
| `memgraph-cypher-syntax` | Write, fix or optimize Cypher for Memgraph, including BFS/DFS/WSP lambdas, text search and vector search |
| `memgraph-model-graph-data` | Design a graph data model, decide between properties and relationships, or import CSV/Parquet data |
| `memgraph-indexes-and-constraints` | Create and manage indexes, constraints and enums, and run `ANALYZE GRAPH` |
| `memgraph-database-configuration` | Configure triggers, transactions, isolation levels, storage modes, snapshots, WAL and memory |
| `memgraph-run-mage-algorithms` | Run MAGE algorithms such as PageRank, community detection, centrality, embeddings and path traversals |
| `memgraph-graph-rag` | Build a GraphRAG system: schema design, ingestion, hybrid retrieval and agent tool contracts |
| `memgraph-python-query-modules` | Build custom query modules in Python with the `mgp` API |
| `memgraph-cpp-query-modules` | Build custom query modules in C++ with the `mgp.hpp` API |
| `memgraph-rust-query-modules` | Build custom query modules in Rust with the `rsmgp-sys` API |
| `memgraph-mgconsole-cli` | Connect with `mgconsole`, run queries and configure output |
| `memgraph-lab-write-gss` | Style graph visualizations in Memgraph Lab with Graph Style Script (GSS) |
| `memgraph-brand-ui` | Generate UIs, dashboards and diagrams in the Memgraph brand style |

The full content of each skill is in the
[memgraph/skills](https://github.com/memgraph/skills) repository.
