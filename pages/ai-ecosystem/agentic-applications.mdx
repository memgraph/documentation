# Build agentic applications

AI agents need structured context to act on, a memory that keeps what they've
learned, and a way to plan multi-step work. Memgraph provides all three as a
graph.

- [Memgraph MCP server](/ai-ecosystem/agentic-applications/mcp): Connect agents
  and LLM clients such as Claude to your Memgraph database over the Model
  Context Protocol (MCP).
- [AI memory](/ai-ecosystem/agentic-applications/ai-memory): Give an agent
  long-term semantic, episodic and procedural memory as one graph, and recall it
  with a single traversal.
- [Agentic AI](/ai-ecosystem/agentic-applications/agentic-ai): Let agents plan by
  traversing a reasoning graph on a shared data layer instead of by prompting.

To let an agent answer questions from your knowledge graph, see [Agentic
GraphRAG](/ai-ecosystem/graph-rag/agentic-graphrag). To build agents with
LangChain, see the [Memgraph toolkit for
LangChain](/ai-ecosystem/integrations/langchain#memgraph-toolkit).
