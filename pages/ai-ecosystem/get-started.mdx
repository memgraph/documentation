# Start with graph + AI

Every AI application on Memgraph needs three things: a running Memgraph
instance, your data modeled as a graph, and a way for your code or LLM to
query it.

## Prerequisites

GraphRAG systems involve combining graph databases with LLMs. Here’s what you’ll
need to set up for success:

- A running Memgraph MAGE instance. If you’re new to Memgraph, follow the
  [getting started guide](/getting-started).
- Knowledge graph stored in Memgraph - identify your structured or unstructured
  data to convert into a knowledge graph and follow Memgraph's [data
  modeling](/data-modeling) docs to design your graph. 
- LLM API - use the large language model of your choice.

<Callout>
Building a GraphRAG system involves multiple building blocks, and selecting the
right ones isn’t straightforward. 

Before you begin, carefully consider what information the LLM needs that it
wouldn’t have without the knowledge graph. Identify the key context to provide,
and prioritize the most relevant data for inference. 

Remember, creating an ideal system rarely happens on the first try—iteration and
evaluation are essential. 
</Callout>

### Hardware requirements

Since Memgraph is an in-memory graph database, the hardware requirements depend
on the size of your dataset and the complexity of your queries.

1. **Memory**: Sufficient RAM is essential for storing and processing your
   dataset in memory. To estimate your needs, refer to
   our [RAM calculation guide](/help-center/faq#how-much-ram-do-i-need-for-my-graph).
2. **Storage**: While Memgraph operates in memory, storage is required for
   backups, snapshots, and write-ahead logs (WAL) to ensure data durability.
   Learn more about best practices in
   our [storage FAQ](/help-center/faq#what-are-the-minimum-and-recommended-requirements-to-run-a-on-premise-instance).

## Connect your code with the Memgraph Toolbox

The [Memgraph Toolbox](https://github.com/memgraph/ai-toolkit/tree/main/memgraph-toolbox)
is a Python library of tools for querying and inspecting a Memgraph database,
such as running Cypher and searching the graph schema. The [Memgraph MCP
server](/ai-ecosystem/agentic-applications/mcp) and the [LangChain
integration](/ai-ecosystem/integrations/langchain) are built on it, and you can
call the same tools from your own code or framework.

```bash
pip install memgraph-toolbox
```

The toolbox is part of the [Memgraph AI
Toolkit](https://github.com/memgraph/ai-toolkit), which also includes the MCP
server, the LangChain and LightRAG integrations, Unstructured2Graph, SQL2Graph
and Context Graph.

## Create a knowledge graph

Your AI application is only as good as the graph behind it. [Knowledge graph
creation](/ai-ecosystem/get-started/knowledge-graph-creation) explains how to
model your domain and build the graph from structured or unstructured data:

- [SQL2Graph](/ai-ecosystem/get-started/knowledge-graph-creation/sql2graph-agent):
  Migrate a relational database to Memgraph, with optional LLM-assisted
  modeling.
- [Unstructured2Graph](/ai-ecosystem/get-started/knowledge-graph-creation/unstructured2graph-agent):
  Turn documents, PDFs and URLs into a knowledge graph.
