# Get started with Context Graph

One command installs Context Graph, finds or starts Memgraph, and connects
every coding agent it finds on your machine. Setup shows its plan and changes
nothing until you confirm.

## Prerequisites

- **A terminal.** Setup asks its questions there.
- **Docker**, unless you already run Memgraph. Setup starts Memgraph in a
  container. See [Get Docker](https://docs.docker.com/get-docker/).
- **Your own Memgraph, if you don't use Docker:** Memgraph 3.6 or later. For
  recall by meaning, use the [MAGE](/advanced-algorithms) image
  (`memgraph/memgraph-mage`) with at least 2 GiB of memory; without MAGE,
  recall falls back to text search.
- **At least one supported agent** on your `PATH`: Claude Code, Codex, GitHub
  Copilot CLI, Cursor, OpenCode, Antigravity CLI or Grok Build.

You don't need Python. Setup installs [uv](https://docs.astral.sh/uv/) if it's
missing, and uv installs the rest.

## 1. Run setup

Run setup from the project directory you work in. Claude Code and Codex are
connected for your user, but the other agents are connected one project at a
time, starting with the current directory.

<Tabs items={['Linux/macOS', 'Windows']}>
<Tabs.Tab>
```bash
curl -sSL https://install.memgraph.com/ai-memory | bash
```
</Tabs.Tab>
<Tabs.Tab>
In PowerShell 5.1 or 7:

```powershell
iwr https://install.memgraph.com/ai-memory/windows -useb | iex
```

If Windows blocks the script, allow scripts for the current session first:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
</Tabs.Tab>
</Tabs>

Setup lists what it found and what it will do:

- **Agents:** the agents on your `PATH`, ticked. Untick any you don't want
  connected.
- **Memgraph:** the one it will use or start.
- **Name:** your user ID in the graph. Your memories are filed under it. It
  defaults to your git `user.name`, or your system user name.
- **Memory:** whether your agents use Context Graph as their memory instead of
  their own. See [Use Context Graph as your agents' memory](/ai-ecosystem/ai-memory/context-graph/recall-and-memory#use-context-graph-as-your-agents-memory).

The plan updates as you change your choices. Nothing changes until you press
**Install**.

Without a terminal, for example in CI, the install command only prints the
setup command to run. Set `AI_MEMORY_SKIP_SETUP=1` to get the same behavior on
a terminal.

## 2. What setup does

Setup runs these steps in order. Each step checks first, so running setup
again only does what's missing.

1. **Finds or starts Memgraph.** Setup uses the Memgraph in its configuration
   file, then a Memgraph on `localhost:7687`. Otherwise, it starts the
   `memgraph/memgraph-mage` image in a container named
   `context-graph-memgraph`, with a data volume, listening on `127.0.0.1`
   only. If port 7687 is taken, it picks a free port.
2. **Saves the configuration:** the Memgraph URL and your user ID, in
   `~/.config/context-graph/config.toml`.
3. **Installs the packages:** the `memgraph-context-graph` command, the
   packages that record actions, skills and sessions, and the terminal viewer.
4. **Connects your agents.** See [Agents](/ai-ecosystem/ai-memory/context-graph/agents)
   for what changes for each one.
5. **Checks the setup,** the same way as
   [`memgraph-context-graph doctor`](#3-check-the-setup).

The report ends with the command to rerun for any step that failed.

## 3. Check the setup

Restart any agent sessions that were running during setup, because a running
session keeps the hooks it started with. Then check the setup:

```bash
memgraph-context-graph doctor --runtime claude-code
```

Replace `claude-code` with the agent you want to check: `codex`,
`copilot-cli`, `cursor`, `opencode`, `antigravity-cli` or `grok`. Every line
starts with `OK` when the setup works:

```plaintext copy=false
OK memgraph-context-graph executable: ...
OK memgraph-context-graph: ...
OK config: identity.user_id set
OK memgraph: reachable
OK connector:skills-graph: installed=...; memgraph=reachable
OK connector:actions-graph: installed=...; memgraph=reachable
OK connector:sessions-graph: installed=...; memgraph=reachable
OK embeddings: BAAI/bge-small-en-v1.5 (384 dimensions) inside Memgraph
OK mcp: serves recall
OK runtime:claude-code: strict hook smoke passed
```

A line that starts with `FAIL` says what failed. The `embeddings` check fails
on a Memgraph without MAGE; recall then uses text search only.

## 4. Use your agents

Work with your agents as before. Every session is recorded in the graph as it
happens, with secrets redacted. To keep text out of the graph, wrap it in
`<private>` tags, or exclude a project; see
[Keep secrets out of the graph](/ai-ecosystem/ai-memory/context-graph/configuration#keep-secrets-out-of-the-graph). To see it, open the terminal viewer:

```bash
memgraph-context-graph ui
```

In a new session, ask the agent about earlier work, for example "what did we
decide about the deploy window?". The agent calls the `recall` tool and
answers from your past sessions. You can run the same search yourself:

```bash
memgraph-context-graph recall "what did we decide about the deploy window?"
```

## Choose agents and options

Every choice in setup is also a flag of `memgraph-context-graph setup`. After
the first install, run setup again with flags to change your choices:

```bash
memgraph-context-graph setup codex --memgraph-url bolt://memgraph.example.com:7687
```

To pass flags on the first install, run Context Graph's install script and
add them after `bash -s --`:

```bash
curl -fsSL https://raw.githubusercontent.com/memgraph/ai-toolkit/main/context-graph/scripts/install.sh | bash -s -- codex --memgraph-url bolt://memgraph.example.com:7687
```

| Flag | What it sets |
| --- | --- |
| `RUNTIME ...` | The agents to connect: `claude-code`, `codex`, `copilot-cli`, `cursor`, `opencode`, `antigravity-cli` or `grok`. The default is every agent on your `PATH`. |
| `--project-dir DIR` | A project to connect the per-project agents in. Repeat it for more projects. The default is the current directory. |
| `--memgraph-url URL` | The Memgraph to use, instead of finding or starting one. |
| `--user-id NAME` | Your user ID in the graph. The default is the configured one, then your git `user.name`. |
| `--memory-backend context-graph` | Make Context Graph the agents' memory. `native` gives memory back to the agent. |
| `--memgraph-container NAME` | The container to find or start. The default is `context-graph-memgraph`. |
| `--no-viewer` | Don't install the terminal viewer. |
| `--plan` | Print what setup would do and change nothing. |
| `--no-tui` | Print plain output, even on a terminal. |

On Windows, the piped command can't take arguments. Set them in
`CONTEXT_GRAPH_SETUP_ARGS` first:

```powershell
$env:CONTEXT_GRAPH_SETUP_ARGS = 'codex --user-id alice'
iwr https://install.memgraph.com/ai-memory/windows -useb | iex
```

To connect another project for the per-project agents, run setup from that
project, or pass `--project-dir`:

```bash
memgraph-context-graph setup cursor --project-dir ~/work/billing --project-dir ~/work/crawler
```
