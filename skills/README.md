# Documentation release skills

Each skill lives in its own folder. Cursor requires the file to be named
`SKILL.md`, so use the **folder name** to tell them apart.

| Skill (folder) | Purpose |
| --- | --- |
| [check-release-milestone](./check-release-milestone/SKILL.md) | Audit milestone docs labels, changelog coverage, and docs PRs before/during a release |
| [new-release-branch](./new-release-branch/SKILL.md) | Create a release branch, scaffold release-note titles, and open the tracking PR |
| [pre-release](./pre-release/SKILL.md) | Final pre-publish steps (release dates, direct download links) |
| [write-changelog-item](./write-changelog-item/SKILL.md) | Write one changelog / release-note bullet and sync the docs tracking PR |

Open `./<skill-folder>/SKILL.md` for the full instructions.
